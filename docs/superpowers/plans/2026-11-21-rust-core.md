# Rust 核心实施计划

依照[架构](../specs/2026-11-21-cs2world-core-design.md)与[字节对照](../specs/2026-11-21-cs2world-wire.md)，各任务按正常产品入口验收。

- 协议。在 `crates/cs2world-proto` 将握手、AEAD、重放窗口、A2S、整形及 URI 接入无 I/O 的编解码器。以固定输入运行字节对照及双向加解密。
- 传输。实现 KCP、FEC、smux、Socksaddr 与 UoT，测试多段拼包、恢复、半关闭和窗口边界。在 `cs2world-core/src/tunnel.rs` 驱动状态机与 UDP 会话，确保关闭清理队列和密钥。
- 运行时。在 `config/route/mixed/service` 模块接入分流、Mixed TCP/UDP 入站和统计；单文件服务端通过同一运行时路由到目的端。在回环中以 Go、Rust 分别作客户端与服务端，显式走 Mixed 端口，验证 HTTP、TCP、UDP 来源与业务字节。
- 桌面端。迁移 `win32-xp/src/core_manager.rs`，将连接生命周期放到后台。验证已有配置、探针和导入导出，以及连接期间的窗口消息响应；实际发布目录只分发主程序。
- 平台层。接入真实 TUN 设备、用户态协议栈、C 和 JNI 生命周期，按目标平台编译打包，将设备依赖与系统权限的实测结果分别记录。Linux 检查静态 ELF 并启动服务。
